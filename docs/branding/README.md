# Branding

Mod icons, drawn by script from the mods' own art (owner picks 2026-10-15):

- **MaxTech Storage:** the sigil seal: the runic controller face inside a glowing ring (`maxtech_storage_icon_*.png`).
- **MaxTech Lib:** the MT monogram in runic grooves, without glow (`maxtech_lib_icon_*.png`).

`render_storage.html` and `render_lib.html` draw the 512 px versions in a browser; the 256 px project icons and the
128 px `logoFile` images in each neoforge jar (`<modid>_logo.png`, set in `neoforge.mods.toml`) are scaled from them.
