# Showcase scenes

Structure files of the screenshot scenes, one per scene (`hall.nbt`, `crafting.nbt`, `processing.nbt`,
`monitoring.nbt`, `cables.nbt`), written by `/maxtech_storage scene save <scene>` in a dev run. They are vanilla
structure files (gzip NBT) of the scene's 13 x 9 x 13 box, from two layers under the floor up.

None is committed yet: until a scene has a file, `/maxtech_storage scene place` and `shoot scenes` build the code draft
in `ShowcaseScenes`. Commit a file once the scene looks right in-game. How to place, fix and shoot the scenes:
`docs/release/screenshots.md`.
