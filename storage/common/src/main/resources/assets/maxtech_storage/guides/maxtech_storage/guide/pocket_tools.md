# Pocket uplink and restock belt

Both work within the network's wireless range ([wireless](signal.md)); bind them by sneak-using on a controller.

The <ItemLink id="maxtech_storage:pocket_uplink" /> stores items your inventory has no room for in the network. Use it
with an item in the other hand to filter by that item.

<RecipeFor id="maxtech_storage:pocket_uplink" />

The <ItemLink id="maxtech_storage:restock_belt" /> tops up marked slots from the network. Use it to open it, left-click a
slot to mark it.
