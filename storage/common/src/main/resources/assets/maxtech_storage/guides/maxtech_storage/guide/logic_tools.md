# Signal probe and puzzle cartridge

The <ItemLink id="maxtech_storage:signal_probe" /> graphs how busy one block's link is. Use it on a storage cable or
device to bind it, then use it in the air: the share of the link's [channels](cables.md) in use, one sample a second for
the last minute, with the peak. A device always near 100 % has a link that is the bottleneck.

<RecipeFor id="maxtech_storage:signal_probe" />

A <ItemLink id="maxtech_storage:puzzle_cartridge" /> carries one [research](research.md) puzzle. Use a blank one to get
a random puzzle, a written one to reopen it. Solving it uses the cartridge up and gives your team
<Config key="tools.cartridge.creditPercent" unit="%" /> of a skip token's points.
