# Bulk Drives

The <ItemLink id="maxtech_storage:bulk_drive" /> stores one item kind in huge numbers. It holds no cells: the first item
put in locks it to that kind, and it clears again when empty.

<BlockImage id="maxtech_storage:bulk_drive" scale="3" />

Use it with a stack to insert, sneak-use with an empty hand to take a stack, or use with an empty hand to open its
screen and set its priority, as for [drives](cells.md). It joins the network like any device and needs its research.
It keeps its items and priority when picked up.
