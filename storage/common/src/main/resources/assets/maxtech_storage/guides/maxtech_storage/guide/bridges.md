# Network bridges

A <ItemLink id="maxtech_storage:network_bridge_tier_1" /> links a Storage network with an AE2 or Refined Storage network.
Place it against a cable or device of the other network; its back links to your cables.

Both sides see and use each other's storage; nothing is copied. Crafting stays on each side. Tiers 2 and 3 move more,
like [ports](ports.md).
