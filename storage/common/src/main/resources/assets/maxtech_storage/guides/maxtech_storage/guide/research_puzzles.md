# Research puzzles

A node with a puzzle option can be completed by solving a puzzle instead of a task or points. Pick the option on the
[research](research.md) screen. Wrong answers are free; the server checks the solution again.

| Puzzle | Used for | Goal |
|---|---|---|
| Signal routing | network nodes | Turn tiles so the wire lights every output. |
| Mask alignment | processor nodes | Turn (and later flip) masks until the exposure matches. |
| Byte packing | memory nodes | Fit items into banks without overfilling. |
| Waveform tuning | signal and wireless nodes | Set the dials until your wave matches. |

Each has three difficulties; the node names the one it needs. Click or use the arrow keys to play. Every shipped node
with a puzzle also has a task and a points option.
